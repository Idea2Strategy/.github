# Idea2Strategy

> 투자 아이디어를 봇으로 실행하고, 데이터로 검증하는 가상 트레이딩 플랫폼

## 프로젝트 소개

Idea2Strategy는 투자 아이디어를 가지고 있지만 이를 코드로 구현하거나 시장 데이터와 연결하기 어려운 사용자를 위한 서비스입니다.

사용자는 템플릿과 블록형 전략 편집기를 이용해 종목, 매수·매도 조건, 지표와 주문 설정을 직접 구성할 수 있습니다. 완성된 전략은 가상 트레이딩 봇으로 변환되며, 과거 시장을 대상으로 하는 **백테스트**와 현재 시장 흐름을 반영하는 **라이브 모의투자**를 통해 검증됩니다.

단순히 최종 수익률만 제공하는 것이 아니라 봇의 판단, 주문과 체결 과정을 함께 기록합니다. 이를 통해 사용자는 자신의 전략이 어떤 조건에서 작동했는지 확인하고, 수익률·최대 낙폭(MDD)·변동성·거래 횟수 등 다양한 지표를 바탕으로 전략을 개선할 수 있습니다.

## 프로젝트 목표

Idea2Strategy는 좋은 투자 아이디어가 기술적인 장벽 때문에 검증되지 못하는 문제를 해결하고자 합니다.

1. **Define - 전략 구성**  
   사용자가 매수·매도 규칙과 실행 조건을 직접 정의합니다.
2. **Execute - 봇 생성 및 실행**  
   검증된 전략으로 가상 트레이딩 봇을 생성합니다.
3. **Validate - 검증 및 개선**  
   과거와 현재 시장에서 결과와 작동 과정을 확인하고 전략을 개선합니다.

## 핵심 기능

- **전략 편집기**: 템플릿을 선택하고 종목, 조건, 수치와 주문 방식을 설정해 전략을 작성합니다.
- **가상 트레이딩 봇**: 확정된 전략 버전을 봇으로 생성하고 판단부터 주문, 체결까지 기록합니다.
- **백테스트**: 원하는 과거 기간에서 수수료와 슬리피지를 반영한 전략 성과를 확인합니다.
- **라이브 모의투자**: 현재 시장 데이터를 이용해 실제 자금 없이 전략의 작동을 확인합니다.
- **성과 분석**: 수익률뿐 아니라 MDD, 변동성, 거래 횟수 등 여러 지표를 함께 제공합니다.
- **대회 및 리더보드**: 기간, 초기 자금과 거래 비용이 같은 환경에서 봇의 실험 결과를 비교합니다.
- **AI·CLI 연동**: 외부 AI가 전략 초안 작성과 구조 점검을 보조하며, 전략 출시와 봇 실행은 사용자가 최종 결정합니다.

## 서비스 원칙

Idea2Strategy는 수익을 약속하거나 특정 종목, 전략, 매매 시점과 투자 비중을 추천하지 않습니다. 투자금을 보관하거나 실거래 주문을 전달하지 않으며, 다른 사용자의 전략을 그대로 복제하는 기능도 제공하지 않습니다.

AI는 전략 작성을 보조할 수 있지만 잠긴 전략의 수정, 전략 출시 승인과 봇 실행·중단에 관한 결정은 사용자에게만 부여됩니다. 순위와 성과 지표 역시 투자 추천이 아닌 동일 조건에서 진행한 실험 결과로 제공합니다.

Team B205는 프로젝트 관리, 프론트엔드, 백엔드, 인프라와 데이터 영역을 나누어 하나의 서비스로 개발합니다.

| 이름 | 역할 | 담당 업무 |

| 민경철 | Project Manager | 제품 방향 수립, 프로젝트 일정 관리, 주요 의사결정 및 팀 협업 조율 |
| 서동위 | Frontend | 블록형 전략 편집기, 서비스 화면, 사용자 경험 설계 및 구현 |
| 손현준 | Backend | 전략·봇·주문·체결 처리와 성과 관련 서버 기능 설계 및 구현 |
| 박준유 | Backend | 전략·봇·주문·체결 처리와 성과 관련 서버 기능 설계 및 구현 |
| 나주원 | Infrastructure | 서버 및 컨테이너 환경 구축, 배포와 서비스 운영 구조 설계 |
| 황영우 | DB / Data | 시장 데이터 수집·저장, 서비스 데이터 모델과 실시간 데이터 구조 설계 |

## 우리가 만들고자 하는 것

Idea2Strategy는 수익을 보장하는 서비스가 아니라, 사용자가 자신의 투자 규칙을 직접 만들고 객관적인 데이터로 제대로 시험할 수 있는 환경을 지향합니다. 전략의 결과뿐 아니라 그 결과가 만들어진 과정까지 확인할 수 있도록 하여, 아이디어가 검증 가능한 전략으로 발전하는 과정을 돕습니다.
